# GitHub User Finder

A simple, responsive web application to search for GitHub users and view their profiles using the GitHub Users API.

## Features

- **User Search**: Search for any GitHub user by their username.
- **Profile Display**: detailed view including:
  - Avatar image
  - Name (or username if name is not available)
  - Bio
  - Direct link to the GitHub profile
- **Error Handling**: Friendly message when a user is not found.
- **Keyboard Support**: Press `Enter` to trigger the search.
- **Responsive Design**: Clean and simple card layout that works on different screen sizes.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- [GitHub API](https://docs.github.com/en/rest/users/users)

## How to Use

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Enter a GitHub username in the search bar.
4. Click "Search" or press Enter.
